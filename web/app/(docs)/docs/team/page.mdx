# Team & Invites

<p className="text-base text-foreground/80 leading-relaxed mt-2 mb-8">

## Roles

Every project member has one of three roles:

**Owner** — full control. Can modify the contract, publish, invite members, change roles, and delete the project. The person who creates a project is the owner by default.

**Editor** — can modify the contract, publish new versions, and invite new viewers. Cannot delete the project or change billing.

**Viewer** — read-only access. Can view the contract, copy generated outputs, and receive change alerts. Cannot modify the contract or publish.

External partners and clients should always be invited as viewers.

## Inviting a teammate

Go to **Project Settings → Team** and enter the email address of the person you want to invite. Select their role and click **Send Invite**.

Invokix sends them an email with a link to accept the invite. When they accept, they are added to the project immediately. If they do not have an Invokix account yet, the invite link takes them through signup first.

Invite links expire after 7 days. You can resend or revoke a pending invite from the same settings page.

## Managing existing members

From the Team settings page you can:

- Change a member's role at any time
- Remove a member from the project
- See when each member last pulled the contract via the CLI
- See which version each member is currently on

## External partners as viewers

If you are sharing your API contract with an external partner — a client, an integration partner, or a third-party developer — invite them as a viewer. They get access to:

- The full contract in read-only mode
- All generated code outputs — types, hooks, schemas
- The mock server URL
- The auto-generated changelog
- Change alerts when the contract updates

They cannot modify anything. You can revoke their access at any time.
