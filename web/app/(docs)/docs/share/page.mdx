## Your shareable link

Every project has a permanent public URL:

<DocsCode lang="text" title="Your contract share URL">
{`https://invokix.com/share/your-project-id`}
</DocsCode>

Anyone with this link can view your contract without creating an Invokix account. The page always shows the latest published version — you never need to update the link after publishing.

## What visitors see

The share page gives external developers everything they need to consume your API:

- Full contract — every endpoint with request and response schemas
- One-click copy for TypeScript types
- One-click copy for React Query v5 hooks
- One-click copy for Zod schemas
- One-click copy for React Native hooks
- Mock server URL — ready to use immediately
- Auto-generated changelog — every version diff in plain English
- Current version number and last published date

## Who to share it with

**External integration partners** — give them the link instead of sending PDF docs or Notion pages. They always have the latest version. When you publish a new version, their link updates automatically.

**Client developers** — clients building on top of your API get types and hooks in one click. No back-and-forth email chains.

**New team members** — the share page is the fastest onboarding doc for any engineer joining the project. Everything they need is in one place.

**Open source API consumers** — if your API is public, the share page is your public API documentation.

## Keeping the link private

If you do not want your contract to be publicly accessible, go to **Project Settings → Sharing** and disable the public share link. Only invited team members can access the contract while the link is disabled.

You can re-enable the public link at any time.
