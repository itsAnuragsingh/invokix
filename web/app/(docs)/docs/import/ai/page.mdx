## How it works

Type a natural language description of your API. Be specific about what operations users can perform, what data is involved, and what authentication your API uses. Invokix generates a complete OpenAPI 3.0 contract and opens it in the editor for you to review before publishing.

The generated contract includes:

- Every endpoint with correct HTTP methods and paths
- Request and response schemas with proper types
- `401` and `500` error schemas on every endpoint
- JWT or API key security schemes if you mention authentication
- Realistic example values on every field — not just `string` and `number`
- A starting Health Score so you know what to improve

## Tips for better output

The more specific your description, the better the output:

- **Name your fields explicitly** — "each order has an `id`, `price`, `status`, and `createdAt`" produces better schemas than "each order has some data"
- **Specify your auth method** — "JWT bearer token", "API key in header", or "no authentication"
- **List every operation** — create, read, update, delete, cancel, search, filter, paginate
- **Describe relationships** — "each order has line items, each line item has a product ID, quantity, and price"
- **Mention payment providers** — Razorpay, Stripe, or others help the AI generate appropriate webhook and payment endpoints
