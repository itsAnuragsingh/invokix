# Slack Alerts

<p className="text-base text-foreground/80 leading-relaxed mt-2 mb-8">
  When a contract changes, every affected team member knows within 30 seconds. Slack, Discord, and email alerts deliver the exact diff — what changed, who changed it, and what needs updating — directly to your team.
</p>

## Setting up Slack alerts

Go to **Project Settings → Alerts**. Paste your Slack incoming webhook URL and click Save. That is the entire setup — no OAuth, no Slack app approval, no bot installation.

To create a webhook URL in Slack:
- Go to `api.slack.com/apps`
- Create a new app or open an existing one
- Enable **Incoming Webhooks**
- Add a new webhook and select the channel you want alerts posted to
- Copy the webhook URL and paste it into Invokix

## Discord alerts

Paste your Discord channel webhook URL into **Project Settings → Alerts → Discord Webhook**. Discord webhooks work identically to Slack — the same alert format is delivered to your Discord channel.

To get a Discord webhook URL: open your Discord server settings → Integrations → Webhooks → New Webhook. Select the channel and copy the URL.

## Email alerts

Add email addresses under **Project Settings → Alerts → Email Recipients**. Every address in the list receives an email alert when the contract is published. You can add as many addresses as you need — individual engineers, team distribution lists, or external partners.

## Alert types

You can configure which events trigger alerts:

**Breaking changes only** — alerts fire only when a breaking change is published. Non-breaking additions and description updates are silent. Recommended for most teams.

**All changes** — alerts fire on every publish, breaking or not. Useful for external partners who want to know about every update.
